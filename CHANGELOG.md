## [Unreleased]

### Added
- Initial project structure with SwiftUI dark theme
- Keyboard tab with QWERTZ/QWERTY/AZERTY layouts, visual keyboard, Command Dial, roller, media keys
- Mouse tab with vertical mouse visualization for Pro Click V2 Vertical Edition
- Lighting tab with 7 effects, color picker, device-aware preview (keyboard/mouse)
- Key mapper sheet with action types (keystroke, shortcut, app launch, media, macro, disable)
- Test input field for verifying key mappings
- DPI settings with presets and Focus Pro 35K sensor support (up to 35000 DPI)
